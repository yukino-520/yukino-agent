# 独立能力矩阵

这份矩阵按“用户可以完成的事情”核对参考产品，而不是按参考项目文件、类名或界面复刻。所有实现入口均属于 `service_club`。

| 用户能力 | AGI Yukino 独立实现 | 使用入口 | 状态 |
|---|---|---|---|
| 多人格/多 Agent | 五位春物角色、主回应者路由、活动室群像编排 | Chat、CLI、`/api/chat` | 就绪 |
| 任务 Agent | 原生结构化工具调用、最多 1–8 步观察循环、持久工作池、跨会话并行、同会话严格顺序、队列背压/位置、租约心跳、取消竞态保护与启动恢复；任务级时长/调用/Token/费用预算、并发原子预占、不确定费用计量与提额后原账本恢复；模型失败分类、按模型熔断、半开探测、备用模型安全切换与逐轮路由证据；结构化模型循环恢复点（只存摘要/指纹/步骤引用）与安全恢复上下文；持久进度事件与可重连实时执行时间线 | Chat、设置、任务状态/事件 API | 就绪，取决于模型工具协议支持；费用闸门需配置模型单价 |
| 代码分析 | 语言识别、Python AST 语法、通用安全初检与模型语义审查；模型失败时基于确定证据生成可读降级审查而非转储 JSON | Chat | 就绪 |
| 认知闭环 | 情绪、画像、关系、反思、互动学习、自我模型 | 对话自动运行、侍奉记录 | 就绪 |
| RAG/记忆 | PostgreSQL 唯一事实层、Elasticsearch BM25、独立文档分块索引、RRF 融合、pgvector、可选 Milvus/Neo4j 投影、删除一致性、永久记忆与上下文压缩 | Chat、Memory API、设置 → 记忆数据库、存储 CLI | 就绪；语义通道需 Milvus 与 Embedding 配置 |
| 知识图谱 | 关系事实表、稳定 ID、会话隔离、证据哈希、显式编辑与规则化自动观察、单跳检索扩展、可选 Neo4j 幂等投影和重建 | Chat、设置 → 记忆数据库、CLI | 关系图谱就绪；Neo4j 需独立服务 |
| 学习记录 | 错误、需求、模式、偏好的分类与状态追踪 | 部务台 | 就绪 |
| 工具检索 | 原生能力目录检索；无向量配置也可词法工作 | 部务台、`search_capabilities` | 就绪 |
| 能力权限 | 持久整项/动作 deny、当前会话限时限次 grant、原子扣次、随时撤销、确认独立、工作流逐步骤复检 | 设置 → 能力权限、权限 API | 就绪 |
| 文件工具 | 内部工作区读写、项目只读、桌面/自定义目录授权、密钥阻断、覆盖与编辑确认、确认后旧文件 SHA-256 前置条件复检 | 设置、聊天工具 | 就绪 |
| Python | AST/对象图白名单、macOS 拒绝优先系统沙箱、无网络/用户文件/子进程、CPU/内存/句柄/输出限制、后端不可用时拒绝降级 | 设置状态、聊天、`运行 Python：...` | macOS 就绪；其他系统缺少受支持后端时安全拒绝 |
| 网页研究 | DNS/IP 检查、SSRF 防护、超时、正文大小限制 | 部务台、聊天工具 | 需网络 |
| 文档阅读 | 文本/JSON/CSV 原生；PDF/DOCX 按解析库启用 | 部务台 | 基础就绪 |
| 海量知识库 | PostgreSQL 文档/分块事实、Elasticsearch 独立索引、知识库隔离、幂等写入/删除与全量重建 | `/api/knowledge/*`、`storage rebuild-search` | 就绪；外部文件批量导入器可按业务格式扩展 |
| 系统/硬件状态 | CPU、内存、温度、电池、磁盘、GPIO/I2C 探测；结构化白名单系统任务，目录/超时受限，不经过 Shell，确认绑定任务配置指纹 | 设置、聊天工具 | 就绪，硬件按设备降级 |
| 多模态 | 贴纸、可选 TTS、素材上传、OpenAI-compatible 视觉理解 | Chat、部务台 | 需素材/凭证 |
| 笔记/任务/计划 | 原子 JSON 状态库、待办/笔记/计划增删改查 | 部务台 | 就绪 |
| 主动关怀 | 情绪连续性、DND、配额、提醒与回访计划 | 对话自动运行、Nudge API | 就绪 |
| MCP | 显式白名单 HTTP JSON-RPC 与本机 stdio；stdio 使用官方 Python SDK 完成初始化/能力协商/关闭生命周期，每次启动单独授权且不经过 Shell；环境变量按服务显式传入、应用密钥不自动继承、stderr 不回显；`tools/list` 工具发现与持久目录、名称/说明/JSON Schema 限量清洗、模型动态选型提示、本地方法边界与独立确认；远端 annotations 不授予权限 | 设置、聊天 Agent、`search_capabilities` | HTTP JSON-RPC 与 stdio 就绪且需配置；有状态 Streamable HTTP 会话恢复尚未支持 |
| 插件 | 清单注册、权限声明、启用状态机 | 部务台 | 就绪 |
| 工作流 | 最多 8 步、依赖拓扑、类型化输出引用、逐步 PostgreSQL 审计、中断识别、同步执行或确认后持久后台执行、完成后回写原任务验收 | 聊天 Agent、设置能力中心、后台作业 API | 就绪 |
| 定时提醒 | 中文相对/绝对时间、IANA 时区、每天/每周重复、PostgreSQL 状态机、租约领取、页面通知、页面关闭后的 Webhook 派送、退避与死信回退 | 聊天 Agent、记忆页、设置页 | 就绪；离线派送需配置 Webhook 并开启 |
| 邮件 | SMTP SSL、配置状态、发送前确认 | 部务台 | 需 SMTP |
| QQ/微信/Webhook | 统一入站消息契约、独立会话命名空间、HMAC-SHA256、5 分钟时间窗、PostgreSQL event_id 防重放 | `/api/channels/{channel}/messages`、设置页 | 接口与验签就绪，平台仍需凭证 |
| Web 实时状态 | WebSocket ready/status/ping、按会话授权的任务事件订阅、PostgreSQL 游标回放、Kafka outbox 事件流与轮询断线补偿 | `/ws/runtime`、任务事件 API、Kafka topic | 就绪 |
| 模型用量/费用 | 按天、模型和 token 汇总，可配置单价估算 | `/api/usage`、`agi-yukino usage` | 就绪 |
| 安全可靠性 | 危机分级、持久能力/动作 deny、会话限时限次 grant 原子扣减、确认独立且绑定非秘密执行目标指纹、确认后配置漂移拒绝、工作流逐步骤权限复检、工具输出来源/摘要与不可信 JSON 数据边界、不可见控制字符清理、提示注入检测与本轮副作用冻结、模型副作用逐项匹配用户执行契约、确定性副作用完成后关闭模型工具模式、未提供的工具调用拒绝、兼容工具标记去重、已验收副作用不因回复超时失效、路径沙箱、Python 系统进程沙箱与拒绝降级、SSRF、AST、确认门禁、确认后全契约复验、持久任务、同账本恢复、结构恢复点、恢复请求幂等、不确定副作用重放门禁、任务级领域幂等键、文件副作用回执/SHA-256 启动对账与覆盖前版本复检、外发 dispatch 账本、稳定供应商幂等键/MCP 请求 ID/邮件 Message-ID、外发崩溃后禁止自动重放、确定完成回执启动认领、按会话外发核对中心、人工确认成功/原标识重试/放弃、并发领取防重、已生效自动认领、未发生安全重试、冲突拒绝覆盖、意图化执行计划、必要证据契约、缺证据拒绝完成、恢复失败识别、工作流完成步骤不重放、后台租约/心跳/退避/停止/死信、队列原子背压、同会话互斥、取消迟到提交保护、热重载隔离、共享状态线程安全、模型失败分类/熔断/安全 fallback、工具执行后禁止模型整轮重放、原子写入/回滚、进程组停止、启动中断与孤儿租约恢复、检查点/审计脱敏、只读网络重试、按目标熔断、模型并发与停止等待 | 全链路 | 就绪；第三方不遵守幂等键或外发终态未知时仍需人工核对 |
| 提示词/质量治理 | 场景复杂度、实验记录、回应策略、质量审计、互动反馈、自我模型 | 部务台、Doctor、Trace API | 就绪 |

“需配置”表示功能代码和入口已经存在，但外部平台、模型或邮件服务本身必须由用户提供凭证。这些凭证不会从参考项目迁移。
